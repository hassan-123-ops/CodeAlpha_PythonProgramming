# CodeAlpha Python Programming Internship

Welcome to my **CodeAlpha Python Programming Internship Projects** repository!

I am a BS Artificial Intelligence student, and this repository contains three Python projects developed as part of my internship learning journey.

## Projects

### 1. Hangman Game
A word-guessing game built using Python.

**Features:**
- Random word selection
- Six incorrect guesses allowed
- Tracks correctly guessed letters
- Uses loops, conditional statements, strings, and lists

**File:** `Task1 (Hangman Game).ipynb`

### 2. Stock Portfolio Tracker
A simple program that calculates the total investment value of selected stocks.

**Features:**
- Supports AAPL, TSLA, MSFT, GOOGL, and AMZN
- Accepts stock symbols and quantities
- Calculates total portfolio value using predefined prices
- Optional CSV file saving

**File:** `Task2 Stock portfolio tracker.ipynb`

### 3. Basic Chatbot
A rule-based chatbot that responds to common user messages.

**Features:**
- Responds to greetings and common questions
- Uses conditional statements and functions
- Continues the conversation until the user exits

**File:** `Task4 Basic Chatbot.ipynb`

## Technologies Used

- Python
- Jupyter Notebook
- Python Standard Library
- CSV file handling

## How to Run the Projects

1. Install Python and Jupyter Notebook.
2. Download or clone this repository.
3. Open Jupyter Notebook.
4. Open the desired `.ipynb` file.
5. Run the notebook cells in order.
